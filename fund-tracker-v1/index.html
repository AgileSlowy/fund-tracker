收益计算规则

  • 净值从 1.0000 开始，根据每天输入的涨跌幅连续计算：当日净值 = 前一日净值 × (1 + 当日涨跌幅)。
  • 业绩走势图以当前所选时间范围内的首个交易日净值为基准，首日显示 0%，之后显示相对该首日净值的涨跌百分比。
  • 首日买入金额会参与首日涨跌；后续追加金额按当日收盘净值买入，不计入当天收益，从下一个交易日开始参与收益计算。
  • 赎回金额按当日收盘净值卖出，并按赎回比例扣减持有成本；当日收益先按赎回前的持仓计算，再处理赎回。
  • 持有收益 = 当前持仓金额 - 当前持有成本；持有收益率 = 持有收益 / 当前持有成本，持有成本为 0 时显示 0%。
  • 累计投入金额 = 历史追加金额 - 历史赎回金额；累计盈亏 = 当前持仓金额 - 累计投入金额。
