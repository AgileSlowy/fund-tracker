# fund-tracker

个人基金记录与收益分析系统。

## 版本说明

### fund-tracker-v1

第一版：纯前端版本，使用 HTML + CSS + JavaScript + LocalStorage，实现本地基金记录、收益计算和图表展示。

### fund-tracker-v2

第二版：Vue3 重构版本，增加 CSV 导入导出、登录注册、多用户本地隔离等功能。

### fund-tracker-v3

第三版：前后端分离版本，使用 Vue3 + Spring Boot 3.x + MySQL 8 + Docker，实现真实登录注册、JWT 认证、多设备同步和共享基金组合权限管理。
